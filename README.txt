***APTTracker
<image>
APTTracker is a plugin for <link-to-HDT | Hearthstone Deck Tracker (HDT)> which is a companion app for Hearthstone (This plugin is for Battlegrounds)

<br>

**Installation
- Install <link-to-HDT | Hearthstone Deck Tracker (HDT)> if needed.
- (Optional) Review HDT <link | plugin installation instructions>
- Download <link | latest release>
- Copy APTTracker.dll into the plugins subfolder (default: %appdata%\Hearthstone Deck Tracker\Plugins) or click Options -> Tracker -> Plugins -> Plugins Folder.
- (Re-)start HDT.
- Enable APTTracker in Options -> Tracker -> Plugins

<br>

**How to Update
- A link will appear in the plugin when an update is available.
<image-of-update notification>
- Download <link | latest release>
- Replace existing APTTracker.dll with newly downloaded one in the plugins subfolder (default: %appdata%\Hearthstone Deck Tracker\Plugins) or click Options -> Tracker -> Plugins -> Plugins Folder.

<br>

**Features
- Updates during the game as you play.
- Number go up !!!
- Obsessively accurate tracking covering every feature for the game.
- Details panel shows breakdown of what actions/events have occurred during the turn.
- Display combat and shop duration (or disable it).
- Display APM (or disable it).
- Rank image/title changes as APT increases.
- Records record highest APT.

It is fun to be able to look at APTTracker after a turn and see:
1. how good the APM was
2. how many of an event we care about. Ex. Playing Turbo Hogrider and seeing how many choose-ones were played. Or playing Abberations and seeing how many discards.

My dream is that streamers will use it so I can see how big APM is of top players and compare them against eachother and myself :)
It can also allow us to compare APM of different boards/comp.
